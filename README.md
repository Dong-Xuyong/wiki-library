# Wiki Library

Kindle-like shelf and reader for YouTube wiki books. Plain HTML/CSS/JS SPA on GitHub Pages (dong-ui theme).

**Live:** https://dong-xuyong.github.io/wiki-library/

## Local preview

```bash
cd wiki-library
python -m http.server 8795
# open http://localhost:8795/
```

## Sync

From the Second Brain repo root (after books data is built):

```bash
python scripts/sync_wiki_library.py
```
